EvenAudio's first Debian package for Ubuntu 24.04 (amd64).

- Seven-band compressor with shared ratio, presets, dark/light themes, and optional voice leveling.
- Application-menu launcher and optional tray controls.
- Prebuilt native DSP; no compiler or pip packages needed after installation.
- Cached Ubuntu build dependencies and compiler outputs in GitHub Actions, with tested releases published to the signed M45 APT repository.

Install with `sudo apt install evenaudio` after adding the M45 Software repository.
Use your existing PulseAudio or PipeWire audio service.
