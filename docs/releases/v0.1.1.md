EvenAudio Debian package for Ubuntu 24.04 (amd64).

- Seven-band compressor, presets, themes, optional voice leveling, and tray controls.
- Precompiled audio engine and application-menu launcher; no build tools needed at runtime.
- Cached APT archives and native object compilation in GitHub Actions.
- Tested releases automatically update the signed M45 APT repository.

After adding the repository, install with `sudo apt update && sudo apt install evenaudio`.
Uses your existing PulseAudio or PipeWire audio service.
